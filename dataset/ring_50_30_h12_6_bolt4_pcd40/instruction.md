Create a bolted ring.

Requirements:
- Axis is global Z.
- Outer diameter: 50.0 mm.
- Inner through-bore diameter: 30.0 mm.
- Height: 12.0 mm.
- Bottom face on z=0 and entire part in z>=0.
- Add six through bolt holes: diameter 4.0 mm on a 40.0 mm bolt circle
  at angles 0, 60, 120, 180, 240, 300 degrees.

Submission contract

Create `/workspace/final.py`. The file must run with Python 3.11 and Build123D 0.10.0, and it must leave the completed model in a top-level variable named `part`. The verifier evaluates that object directly.
