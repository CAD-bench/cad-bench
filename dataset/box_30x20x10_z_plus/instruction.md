Create one rectangular box.

Requirements:
- Dimensions: 30.0 mm (X) x 20.0 mm (Y) x 10.0 mm (Z).
- Faces aligned with global axes.
- Bottom face lies on z=0 and the part is entirely in z>=0.
- Center on X/Y is at (0, 0).

Submission contract

Create `/workspace/final.py`. The file must run with Python 3.11 and Build123D 0.10.0, and it must leave the completed model in a top-level variable named `part`. The verifier evaluates that object directly.
