# Start Here

This bundle is intentionally small. Read pages in this order and only drill deeper when needed.

Recommended path:
1. Cheat Sheet for syntax refresh.
2. Builder or algebra concepts depending on coding style.
3. Objects and Operations for actual geometry construction.
4. Topology Selection when you need faces/edges after modeling.
5. API references only when you need exact names/signatures.

Curated pages:
- 01. Cheat Sheet [Core Workflow]
  Use when: You need the shortest possible reminder of Build123D syntax and common operations.
- 02. Key Concepts (builder mode) [Core Workflow]
  Use when: You are writing `with BuildPart()` / `with BuildSketch()` style code.
- 03. Key Concepts (algebra mode) [Core Workflow]
  Use when: You want direct solid construction with expressions like `part = body - cut`.
- 04. Objects [Modeling]
  Use when: You need the actual primitive/object constructors available in the API.
- 05. Operations [Modeling]
  Use when: You need shape-building operations after sketches or solids already exist.
- 06. Topology Selection and Exploration [Inspection]
  Use when: You need faces/edges/vertices for post-processing or feature edits.
- 07. Builder Common API Reference [Reference]
  Use when: You know you are in builder mode and need precise function names or signatures.
- 08. Direct API Reference [Reference]
  Use when: You need exact class/function names outside builder mode.
- 09. Moving Objects [Placement]
  Use when: You need `Location`, transforms, or object placement/orientation.
- 10. Import/Export [IO]
  Use when: You need STEP/STL import or export behavior.
- 11. Joints [Assemblies]
  Use when: You are building articulated or constrained assemblies.
- 12. Assemblies [Assemblies]
  Use when: You need multi-part structure instead of a single solid.
- 13. Introductory Examples [Examples]
  Use when: You want compact end-to-end examples before writing code from scratch.
